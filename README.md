# College Fest Website

A responsive sample website for the College Fest Management presentation.

## Features
- College Fest 2026 landing page
- Event cards for music, dance, and games
- Sample event schedule
- Demo registration form with an on-page confirmation message
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in any modern browser.

## Important note
The registration form is a front-end demo only. It does not save submissions or send email. For real registrations, connect the form to Google Forms or a backend service. The existing Google Forms → Google Sheets → Zapier → Gmail workflow can be demonstrated separately.

## Tools in the overall project
Notion, Slack, Zoom, Google Drive, Figma, Zapier, and GitHub.
